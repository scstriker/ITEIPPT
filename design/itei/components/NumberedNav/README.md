# NumberedNav
编号导航条，直接来自 PPT 目录页：左端圆头的序号块 + 深蓝文字条，当前项整条变红。用于目录、分步表单的步骤条、App 的功能入口列表。

**使用者提供**：`items[]`（`number`、`label`、`href`）、`current`（当前项索引）、可选 `done[]`。

**规则**
- 序号用 `numeral` 样式缩到 22px，块宽 72px，左端 `radius-pill` 圆头、右端斜切 `slash`（模板目录序号的原形）。
- 默认项 `brand-navy` 底；当前项 `brand-red` 底（每屏只有一条红）；已完成项 `info-bg` 底 + `brand-navy` 文字。三种态都用 `on-brand` 或 `brand-navy` 文字，保证 ≥6:1。
- 条高 44px（触控友好），条间距 `space-3`，最大宽 520px；手机端撑满减去 `space-4` 侧边距。
- 文字居中（模板如此）；超过两行请缩短文案，不换行。

**不要**：超过 8 条；用它做多级树；给条加圆角（只有序号左端是圆的）。
