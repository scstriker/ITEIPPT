## 1. 系统准备与配置

在使用工具生成 PPT 之前，您需要配置大语言模型（AI）的 API 密钥。

### 1.1 打开 API 配置面板
在页面右上角，点击 **⚙️（齿轮图标）** 打开 API 配置窗口。

> **[图片占位符：界面右上角齿轮图标特写]**

### 1.2 填写配置信息
在弹出的配置窗口中，填写以下信息：
*   **Gemini API Key**：输入您的 API 密钥（必填项）。*注：密钥仅在您的浏览器本地使用，不会上传至任何服务器。*
*   **模型**：选择用于分析和生成的 AI 模型，推荐使用默认的 `Gemini 2.5 Flash`。
*   **API 端点**：如果您需要使用代理，请在此处填写代理地址。通常情况下留空即可。

> **[图片占位符：API 配置弹窗界面，展示三个输入框]**

配置完成后，点击弹窗外部或右上角的 `×` 即可关闭并自动保存配置。

## 2. 第一步：上传文档与基本设置

进入系统后，您将看到“上传文档”的主界面。

### 2.1 基本设置
在页面左侧的“基本设置”面板中，您可以预设 PPT 的基本信息：
*   **目标页数**：期望生成的 PPT 总页数（建议 10-30 页）。
*   **汇报人**：填写您的姓名（将显示在封面页）。
*   **所属机构**：默认填写为“机械工业仪器仪表综合技术经济研究所”，可根据需要修改。

> **[图片占位符：左侧“基本设置”面板截图]**

### 2.2 上传文档
在页面右侧的上传区域：
1.  点击“点击或拖拽上传 PDF/DOCX”区域，选择您要转换的文档。
2.  支持的文件格式：`.pdf` 和 `.docx`。
3.  上传成功后，下方会显示文件名和文件大小。

> **[图片占位符：右侧文件上传区域及上传成功后的文件信息显示]**

### 2.3 提取并分析
确认文档上传无误后，点击右下角的 **“提取并分析 →”** 按钮。
系统将开始读取文档内容，并在下方“文档摘要”区域显示 AI 提取的核心信息（如标题、作者、领域、关键词等）。

> **[图片占位符：“提取并分析”按钮及下方生成的“文档摘要”卡片]**

摘要生成完毕后，点击右下角的 **“下一步：框架规划 →”**。

---

## 3. 第二步：框架规划

在此步骤中，AI 会根据文档内容自动为您生成一份 PPT 框架草案。您可以对其进行自由调整。

### 3.1 框架表格说明
表格中每一行代表 PPT 的一个章节（或部分），包含以下列：
*   **章节名称**：该部分的标题。
*   **分配张数**：该章节预计生成的幻灯片页数。
*   **内容要点**：该章节的核心内容提示。
*   **版式建议**：选择该章节主要使用的幻灯片版式（如：封面、目录、图文单栏、图文双栏等）。
*   **操作**：可删除当前行。

> **[图片占位符：框架规划表格全貌，包含表头和几行示例数据]**

### 3.2 调整框架
*   **修改内容**：直接在表格的输入框中修改章节名称、张数或内容要点。
*   **添加/删除章节**：点击表格下方的 **“+ 添加章节”** 按钮新增一行；点击操作列的 **“删除”** 按钮移除不需要的章节。
*   **AI 智能调整**：如果您对当前框架不满意，可以点击 **“✨ AI 智能调整”**，让 AI 重新为您规划。
*   **重置**：点击 **“重置”** 恢复到最初的框架状态。

> **[图片占位符：表格下方的操作按钮组（添加章节、AI智能调整、重置）]**

调整完毕且确认总页数符合预期后，点击右下角的 **“下一步：内容审计 →”**。

---

## 4. 第三步：内容审计

系统将根据您确认的框架，逐页生成 PPT 的具体内容（文案）。此过程可能需要几十秒钟，请耐心等待。

### 4.1 预览幻灯片内容
生成完成后，页面将以卡片的形式展示每一页幻灯片的详细内容：
*   **页码与版式**：卡片顶部显示当前是第几页以及使用的版式。
*   **标题**：该页幻灯片的主标题。
*   **正文/要点**：该页的核心文字内容。
*   **数据/图表提示**：如果内容包含关键数据，会在此处高亮显示。
*   **演讲备注**：AI 为您生成的配套演讲词。

> **[图片占位符：内容审计页面的幻灯片卡片网格布局]**

### 4.2 检查与修改
请仔细阅读每一页的内容。虽然目前不支持在此页面直接修改文字，但您可以通过审计结果评估内容质量。
*   如果发现重大偏差，可以点击左下角的 **“← 返回框架”** 重新调整重点。
*   如果内容满意，点击右下角的 **“下一步：生成下载 →”**。

---

## 5. 第四步：生成与下载

这是最后一步，系统将把审计好的内容与预设的视觉模板结合，打包成 `.pptx` 文件。

### 5.1 生成过程
进入此页面后，系统会自动开始生成 PPTX 文件。您可以在下方的“运行日志”面板中查看生成进度。

> **[图片占位符：生成页面，显示“正在生成 PPTX 文件...”的提示和日志面板]**

### 5.2 下载文件
生成成功后，页面中央会出现一个巨大的绿色下载按钮。
点击 **“⬇ 下载 PPTX 文件”** 即可将演示文稿保存到您的电脑中。

> **[图片占位符：巨大的绿色“下载 PPTX 文件”按钮]**

### 5.3 开启新任务
下载完成后，如果您需要处理另一份文档，请点击右下角的 **“开启新任务”** 按钮，系统将重置并返回到第一步。

> **[图片占位符：右下角的“开启新任务”按钮]**

## 6. 常见问题解答 (FAQ)

**Q: 为什么点击“提取并分析”后一直没有反应？**
A: 请检查右上角的 API 配置是否正确填写了 Gemini API Key。如果网络环境受限，可能需要配置有效的 API 端点（代理）。

**Q: 生成的 PPT 可以修改吗？**
A: 当然可以。下载的 `.pptx` 文件是标准的 PowerPoint 格式，您可以使用 Microsoft Office 或 WPS 自由编辑其中的文字、调整排版或替换图片。

**Q: 上传的文档有大小限制吗？**
A: 为了保证浏览器的处理性能，建议上传的 PDF 或 DOCX 文件不要过大（通常建议在 50MB 以内）。超长文档在提取文本时可能会被截断。

**Q: 为什么生成的排版有时候文字会超出边界？**
A: AI 生成的文本长度可能存在波动。我们在模板中设置了自动缩放，但如果单页文字过多，仍可能显得拥挤。建议在下载后手动微调，或在“框架规划”阶段增加该部分的幻灯片张数以摊薄内容。
