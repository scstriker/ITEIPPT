# 3. 要求

主要内容是**每页上文下图**，**共16页**，完整的叙述性段落，用1-2句话浓缩核心观点每一页的具体内容如下：

- PPT的第一章（项目背景及必要性），对应**项目建议书**的“目的、意义或必要性”；
- PPT的第二章（项目适用范围及主要内容），对应**项目建议书**的“范围和主要技术内容”和**送审稿**；
- PPT的第三章（项目制定过程），对应**送审稿编制说明**的“一、工作简况”；
- PPT的第四章（技术先进性、创新性、产业化分析），可从**项目建议书**的“目的、意义或必要性”以及“国内外情况说明”提取相关信息；
- PPT的第五章（预期达到的经济社会效益），对应**送审稿编制说明**的“五、预期达到的社会效益、对产业发展的作用等情况”；
- PPT的第六章（其他应予说明的事项），实施主体主要是相关产品制造商，以及**送审稿编制说明**的“十二、其他应予说明的事项”。
- 材料中如果缺少相关内容，根据材料或网上相关信息进行补充完善。
