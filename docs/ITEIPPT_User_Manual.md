# ITEIPPT 用户手册

更新时间：2026-04-11
适用版本：当前仓库主流程（4 步：上传 -> 规划 -> 配图 -> 审计导出）

## 1. 产品简介
ITEIPPT 用于将长文档（PDF/DOCX）快速整理为可审阅、可导出的 PPT 内容。

核心能力：
- 文档解析：提取正文并生成摘要信息。
- 框架规划：按章节/子章节管理内容结构，并结合 AI 给出调整建议。
- 配图导入：支持 ITEI DRAW 提示词生成导入，也支持本地图片直接导入。
- 审计导出：可逐页审阅后导出 `.pptx`。

## 2. 使用前准备
### 2.1 环境要求
- Node.js 20+
- npm
- Chrome/Edge 最新版

### 2.2 本地启动
在仓库 `src` 目录执行：

```powershell
npm install
npm run proxy:dev
npm run dev
```

访问：`http://localhost:3000`

说明：
- `proxy:dev` 是本地 API 代理（默认端口 `8787`）。
- `dev` 是前端开发服务（默认端口 `3000`）。

### 2.3 API Key
在 `src/.env` 配置 `GEMINI_API_KEY`，否则 AI 相关功能不可用。

## 3. 工作流说明（4 步）
## 3.1 Step 1 上传文档
支持格式：
- `.pdf`
- `.docx`

主要操作：
- 上传文档。
- 填写“汇报人”“所属机构”（可选但建议填写）。

系统行为：
- 自动抽取文档标题（首个非空行，若为空回退文件名）。
- 标题会回填到封面信息，所属机构会回填到封面/结束页信息来源。

## 3.2 Step 2 规划框架
主表结构固定为 5 列：
- 序号
- 章节名称
- 子章节数
- 内容
- 删除

子章节表结构固定为 5 列：
- 序号
- 子章节名称
- 布局提示
- 内容
- 删除

关键交互：
- 点击章节左侧箭头，直接展开该章节的子章节表。
- 子章节序号采用层级编号，如 `1-1`、`1-2`。
- 删除统一为行尾 `X`。
- “覆盖程度”已并入“内容”列前置显示。
- 右侧中部悬浮按钮“AI 建议调整”可触发全量框架分析。

建议：
- 先把章节结构基本定稿，再点 AI 建议调整，减少反复重算。

## 3.3 Step 3 配图导入
页面顶部已明确两种导入方式：
1. 复制提示词到 ITEI DRAW 生成图片后上传。
2. 直接上传本地图片。

支持能力：
- 单槽位上传/替换/移除。
- 批量导入图片（自动填充空槽位）。
- 右侧中部悬浮 `ITEI DRAW` 跳转按钮：
  - 地址：`https://draw.sensor-cloud.org/`

## 3.4 Step 4 审计预览与导出
在审计页可进行逐页检查与编辑，重点看：
- 标题/正文是否匹配章节语义。
- 图片槽位是否已正确导入。
- 表格/正文布局是否可读。

确认后使用导出按钮生成 `.pptx`。

## 4. 当前渲染逻辑要点
- 封面：采用单标题模式（不再展示空占位计划号/书名括号样式）。
- 内容页二级标题：蓝底会按标题长度自适应，超长可换行并增高，不截断文本。
- 正文高亮：优先按有意义短语映射，高亮不足时整句兜底，避免随机碎片着色。

## 5. 常见问题
### 5.1 AI 功能提示 `missing_api_key`
原因：未配置或配置错误 `GEMINI_API_KEY`。
处理：检查 `src/.env`，重启 `proxy:dev`。

### 5.2 页面打不开（3000/8787 端口冲突）
排查：

```powershell
netstat -ano -p tcp | Select-String ":3000|:8787"
```

### 5.3 Step 2 结构改了但结果不理想
建议：
- 先微调标题再触发 AI。
- 大改结构后再执行一次完整 AI 建议调整。

### 5.4 导出后内容拥挤
建议：
- 缩短子章节标题长度。
- 将长句拆分为两句，优先保留结论性语句。

- 不要把 `GEMINI_API_KEY` 提交到仓库。

- 对外开放时建议配置访问控制（如 Cloudflare Access）。
