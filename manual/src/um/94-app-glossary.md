# 术语表 {#app-um-glossary .appendix}

本附录按汉语拼音顺序列出本手册使用的术语，分为[@tbl-um-glossary-1] 和[@tbl-um-glossary-2]。缩略语见“符号和缩略语说明”。

Table: 术语（A～K） {#tbl-um-glossary-1 cols=20,80}

| 术语 | 定义 |
|---|---|
| AI 补充项 | AI 在原文之外补充的内容，分为常识补充、AI 概括、AI 推理、AI 构建和图表设计 5 种，在“AI补充”页签中查看 |
| 布局 | 正文页下半部分放什么，分为文字、文字 + 表格和文字 + 图片 3 种。界面上称为“布局提示”，由模板或 AI 建议调整决定 |
| 覆盖程度 | 审计预览中每页的覆盖等级，由来源置信度换算而来 |
| 覆盖度 | 执行 AI 建议调整后，每章得到的评估结果，表示文档对这一章的支撑程度，分为高覆盖、中覆盖和低覆盖 |
| 降级 | AI 调用失败或超时，系统改用规则生成结果的情况 |
| 框架 | 章节、子章节及其布局的整体结构，在“规划框架”步骤中编辑 |

Table: 术语（L～Z） {#tbl-um-glossary-2 cols=20,80}

| 术语 | 定义 |
|---|---|
| 来源引用 | AI 给出的正文依据在原文中的位置 |
| 来源置信度 | 正文与原文的关系，分为原文精确引用、原文转述、AI 推断和 AI 补充构建 4 级 |
| 目录过渡页 | 每章开头的页面，列出全部章节并突出当前章 |
| 内容失效 | 生成内容后框架被改动，已生成的内容不再对应当前框架，需要重新生成 |
| 确认对话框 | 执行跳转、编辑、AI 操作、导入和导出之前弹出的确认窗口 |
| 缺失项 | 系统在生成时按规则发现的问题，例如正文太短、由规则补写 |
| 任务 ID | 后端为生成任务分配的编号，显示在进度条上方 |
| 生成任务 | 内容生成在后端的执行单元，有排队中、运行中、已完成和执行失败 4 种状态 |
| 审计 | 导出前逐页核对 AI 生成内容并修改的过程 |
| 图片槽位 | 图片页中放一张图片的位置，每条图片描述对应一个槽位 |
| 图片描述 | AI 为图片槽位写的绘图提示词，可以复制到 ITEI Draw 生成配图 |
| 问题数 | 审计预览中每页的问题条数，等于 AI 补充项数加缺失项数，低覆盖时再加 1 |
| 原文覆盖率 | 正文页中来源置信度为“原文精确引用”的页数所占的百分比 |
| 预设模板 | 系统内置的框架起点，有标准审查汇报、学术研究汇报和自定义 3 种 |
| 语义高亮 | 系统从正文中挑出的最多 2 个关键短语或 1 个整句，导出后显示为红色 |
| 章节 | 演示文稿的一级结构。每章在 PPTX 中有 1 张目录过渡页，导出时最多 6 章 |
| 正文页 | 每个子章节对应的页面，包括子章节标题、正文和下半部分的表格、图片或图片描述 |
| 子章节 | 章节下的二级结构，每个子章节生成 1 张正文页 |
