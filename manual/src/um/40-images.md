# 配图导入 {#ch-um-images}

“配图导入”是第 3 步。这一步只列出布局为“文字 + 图片”的正文页。你可以把 AI 写的图片描述复制到 ITEI Draw 生成配图，也可以直接上传自己的图片。图片只保存在浏览器中，不上传到服务器。

这一步可以跳过。没有导入图片的页面，导出时写入图片描述作为占位文字，见 [@sec-um-img-pptx] 节。

## 页面组成 {#sec-um-img-layout}

{{i:配图导入}}[[Step 3 · 配图导入]]卡片的顶部是导入说明和进度，右侧是[[批量导入图片]]按钮，如[@fig-um-img-top] 所示。

![配图导入卡片顶部：导入说明（编号 1）和“批量导入图片”（编号 2）](shot:img-top){#fig-um-img-top .w95}

{{i:导入进度}}进度写成“当前进度：已导入 x/y，待导入 z。”，y 是全部图片槽位的数量，每导入或移除一张图片随即更新。

导入说明下方，每个图片页占一栏，标题写成“第 n 页 · 子章节名称”，右侧的数字是这一页的槽位数。进入这一步时第一页自动展开，点击标题展开或收起，一次只展开一页。

## 图片槽位 {#sec-um-img-slots}

{{i:图片槽位}}AI 为每个图片页写了一条或多条图片描述，每条描述对应一个图片槽位。[@fig-um-img-page] 是展开后的一页，各元素的作用见[@tbl-um-img-slot]。

![展开后的图片页](shot:img-page){#fig-um-img-page .w95}

Table: 图片槽位中的元素 {#tbl-um-img-slot cols=8,22,70}

| 编号 | 元素 | 作用 |
|---|---|---|
| 1 | 页面标题 | 点击展开或收起这一页 |
| 2 | 图片描述 | AI 写的绘图提示词，只读，可以选中后复制 |
| 3 | [[预览]] | 显示已导入的图片；没有图片时显示[[未上传图片]] |
| 4 | [[复制图片描述]] | 把描述复制到剪贴板 |
| 5 | [[上传图片]] | 选择一张本地图片放入这个槽位；已有图片时按钮变为[[替换图片]] |
| 6 | [[移除]] | 清空这个槽位，没有图片时不可点击 |

## 用 ITEI Draw 生成配图 {#sec-um-draw}

{{i:ITEI Draw}}ITEI Draw 是本所的 AI 绘图工具。“配图导入”步骤的窗口右侧有一个悬浮的[[ITEI DRAW]]按钮，如[@fig-um-img-draw] 所示，点击后在新标签页打开 ITEI Draw。

![悬浮的“ITEI DRAW”按钮](shot:img-draw){#fig-um-img-draw .w25}

**操作步骤**：

1. 展开要配图的页面，点击槽位的[[复制图片描述]]。卡片中显示“已复制第 n 页图片 m 的描述。”。
2. 点击右侧的[[ITEI DRAW]]，浏览器在新标签页打开 ITEI Draw。
3. 在 ITEI Draw 中粘贴描述，生成图片，把图片下载到电脑。
4. 回到 ITEISlides 的标签页，点击这个槽位的[[上传图片]]，选择刚下载的图片，按 [@sec-um-img-upload] 节完成上传。

{{i:图片比例}}导出时，图片会被拉伸到槽位的尺寸，不保持原来的宽高比，见[@tbl-um-img-pptx]。生成配图时尽量按槽位的比例出图：一页只放 1 张图片时，宽高比约 3∶1；放 2 张时，每张约 3∶2。AI 写的描述中有时写着“16:9”，按这个比例出的图放进单图槽位会被压扁。

## 上传、替换和移除 {#sec-um-img-upload}

{{i:图片/上传}}上传一张图片的步骤如下。

1. 点击槽位的[[上传图片]]，在文件选择窗口中选择一张图片。
2. 系统弹出“确认上传图片？”对话框，写明文件名和目标位置，如[@fig-um-img-dialogs] 中（a）所示。
3. 点击[[确认上传]]。预览区显示这张图片，如[@fig-um-img-uploaded] 所示。按钮变为[[替换图片]]，卡片中显示“已更新图片：文件名”，进度数字随之更新。

![配图导入的确认对话框](shot:dlg-image-upload "上传一张图片"){#fig-um-img-dialogs .w100} ![](shot:dlg-bulk "批量导入")

![上传后槽位中的预览图（编号 1）](shot:img-uploaded){#fig-um-img-uploaded .w90}

替换和移除的做法相同：点击[[替换图片]]后选择新图片，在“确认替换图片？”对话框中点击[[确认替换]]；点击[[移除]]后，在“确认移除图片？”对话框中点击红色的[[确认移除]]。移除后卡片显示“已移除图片，可重新上传。”。

图片要满足[@tbl-um-img-rules] 中的规则。

Table: 导入图片的规则 {#tbl-um-img-rules cols=18,82}

| 项目 | 规则 |
|---|---|
| 文件类型 | 浏览器识别为图片的文件，例如 PNG、JPG、GIF。SVG 和 WEBP 也能导入，但系统不转换格式，PPTX 中能否正常显示取决于 PowerPoint 版本，建议先转换为 PNG |
| 文件大小 | 每张不超过 12 MB |
| 对应关系 | 按页码和槽位序号保存。重新生成内容后，图片仍放在原来的页码和槽位上 |
| 保存位置 | 只在浏览器内存中。重新上传文档、点击[[开始新任务]]或刷新页面后清空 |

不符合规则时，卡片中显示错误“文件“文件名”不是图片格式，请重新选择。”或“文件“文件名”超过 12MB，请压缩后再上传。”，槽位保持原样。

## 批量导入 {#sec-um-bulk}

{{i:批量导入}}[[批量导入图片]]一次选择多张图片，按页面顺序填进空槽位。

1. 点击[[批量导入图片]]，在文件选择窗口中按住 ++Ctrl++ 选择多张图片。
2. 系统弹出“确认批量导入图片？”对话框，写明图片数量和当前空槽位的数量，如[@fig-um-img-dialogs] 中（b）所示。
3. 点击[[确认导入]]。图片从第一个空槽位开始依次填入，卡片中显示导入结果，如[@fig-um-img-bulk] 所示。

    ![批量导入后的进度和结果](shot:img-bulk-done){#fig-um-img-bulk .w95}

批量导入有以下规则：

- 只填空槽位，已有图片的槽位不受影响。
- 图片多于空槽位时，多出的图片不使用，提示“已导入 n 张图片，超出的 m 张未使用。”。
- 没有空槽位时，不弹出对话框，提示“当前没有可填充的空槽位，未执行批量导入。”。
- 只要有一张图片不符合[@tbl-um-img-rules] 的规则，整批都不导入。
- 填入的顺序是文件选择窗口给出的顺序，不一定按文件名排序。导入后要逐页核对，放错的图片用[[替换图片]]改正。

框架中没有“文字 + 图片”布局的子章节时，卡片中只有一行提示，如[@fig-um-img-none] 所示。直接点击[[下一步 →]]进入审计预览。

![没有图片页时的配图导入卡片](shot:img-none){#fig-um-img-none .w95}

## 导出时图片的摆放 {#sec-um-img-pptx}

{{i:图片/导出}}导出 PPTX 时，图片放在正文下方的配图区。摆放方式取决于这一页导入了几张图片，见[@tbl-um-img-pptx]。[@fig-um-pptx-images] 是导入两张图片的页面。

Table: 图片在 PPTX 中的摆放方式 {#tbl-um-img-pptx cols=24,76}

| 导入情况 | PPTX 中的效果 |
|---|---|
| 没有导入 | 配图区写“复制以下内容并在 ITEI Draw 生成PPT配图：”，后接图片描述 |
| 导入 1 张 | 居中放置，拉伸为约 22.5 cm × 7.2 cm |
| 导入 2 张 | 左右并排，左图约 11.2 cm × 6.9 cm，右图约 10.8 cm × 7.2 cm |
| 导入 3 张及以上 | 按槽位顺序取前 2 张左右并排，其余图片不导出 |

![导入两张图片的正文页](shot:pptx-images){#fig-um-pptx-images .w70}

## 常见情形 {#sec-um-img-cases}

配图导入的常见情形见[@tbl-um-img-cases]。

Table: 配图导入的常见情形 {#tbl-um-img-cases cols=26,36,38}

| 情形 | 软件的表现 | 处理办法 |
|---|---|---|
| 点击[[复制图片描述]]后提示复制失败 | 浏览器禁止网页写入剪贴板 | 在描述框中选中文字，按 ++Ctrl+C++ 复制 |
| 某些正文页没有出现在列表中 | 只列出布局为“文字 + 图片”的页面 | 需要配图时，在规划框架中执行 AI 建议调整，或换用含图片页的模板，再重新生成 |
| 图片放错了槽位 | 上传后立即生效 | 点击[[替换图片]]换成正确的图片 |
| 导出后图片变形 | 图片按槽位尺寸拉伸 | 按 [@sec-um-draw] 节的比例出图，或在 PowerPoint 中裁剪 |
| 重新生成内容后，图片出现在别的页上 | 图片按页码和槽位保存，框架变了页码也会变 | 逐页核对，移除放错的图片后重新上传 |
| 导入 SVG 或 WEBP 后，PPTX 中图片显示不正常 | 系统不转换这两种格式 | 转换为 PNG 后重新导入 |
| 悬浮的[[ITEI DRAW]]挡住了按钮 | 窗口宽度不足约 1500 像素 | 缩小页面，见 [@sec-um-browser] 节 |
