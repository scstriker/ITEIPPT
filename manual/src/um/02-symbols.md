# 符号和缩略语说明 {#front-symbols}

| 符号或缩略语 | 全称或含义 |
|---|---|
| AI | 人工智能（Artificial Intelligence）。本系统中指 Google 的 Gemini 大模型 |
| API | 应用程序接口（Application Programming Interface）。本手册中指 ITEISlides 后端提供的 HTTP 接口 |
| API Key | 调用 Gemini 所需的密钥，保存在服务器上，用户无需填写 |
| DOC | Word 97～2003 文档格式，本系统不支持 |
| DOCX | Word 2007 及以后版本的文档格式 |
| Gemini | Google LLC 提供的大语言模型服务 |
| HTTP | 超文本传输协议（Hypertext Transfer Protocol） |
| ID | 标识符（Identifier）。本手册中指生成任务的编号 |
| ITEI | 机械工业仪器仪表综合技术经济研究所的英文简称 |
| ITEI Draw | 本所的 AI 绘图工具，用于根据图片描述生成配图 |
| JSON | JavaScript 对象表示法（JavaScript Object Notation），后端与浏览器之间的数据格式 |
| KB、MB | 千字节、兆字节，本系统按 1 KB = 1024 字节、1 MB = 1024 KB 计算 |
| OCR | 光学字符识别（Optical Character Recognition），本系统不提供 |
| PDF | 便携式文档格式（Portable Document Format） |
| PPT、PPTX | PowerPoint 演示文稿；PPTX 是 PowerPoint 2007 及以后版本的文件格式 |
| SVG、WEBP | 两种图片格式。系统不转换它们，建议改用 PNG 或 JPG |
| P3 | 审计预览中页面编号的写法，表示演示文稿的第 3 页 |
| → | 操作顺序，例如“规划框架 → 配图导入” |
